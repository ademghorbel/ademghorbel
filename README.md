## Projects

### ⚡ VoltWise — Solar Forecasting + LLM Battery Agent
> *XGBoost · OpenRouter · OLMo-3.1-32B · Python*

A two-layer energy intelligence system. The forecasting layer uses XGBoost to predict photovoltaic power output (R²=0.7742, MAE=0.2567 kW). The agent layer routes those predictions to an LLM (OLMo-3.1-32B via OpenRouter) which autonomously decides battery actions — **CHARGE**, **DISCHARGE**, or **MAINTAIN** — based on production context.

This is not a dashboard. It's a decision engine.

### 🤖 ALIEN — Multi-Agent AI System *(Contributor @ Talan Internship)*
> *LangChain · LangGraph · MCP · A2A Protocol · Python · Mermaid*

ALIEN is a production multi-agent architecture built during my internship at Talan. My contributions:

- **Generic Agent** — a reusable, configurable agent backbone that other specialized agents are built on top of
- **Mermaid/Graph Agents** — agents that dynamically generate structured diagrams and visual graph outputs from LLM reasoning chains

The system uses LangGraph for agent orchestration, MCP for tool/context management, and A2A protocol for inter-agent communication — an architecture that mirrors emerging industry standards for autonomous AI systems.
